# Bilan

Animation du site web en 2D/3D

---

## Notions

| Thème | Notions |
| --- | --- |
| **CSS** | transform, transition, @keyframes, media queries, prefers-reduced-motion |
| **JavaScript** | querySelector, addEventListener, classList, animationend |
| **GSAP** | to, from, fromTo, timeline, stagger, matchMedia |
| **Phaser** | canvas, boucle de jeu, Scene, physique arcade |
| **Three.js** | scène, caméra, renderer, mesh, lumière, boucle de rendu |

---

## Quel outil pour quel besoin ?

| Besoin | Outil |
| --- | --- |
| Un petit effet : survol, apparition | **CSS** |
| Une séquence, une interface animée | **GSAP** |
| Un jeu 2D | **Phaser** |
| Un objet ou une expérience 3D | **Three.js** |

Et ils se combinent : GSAP a animé la caméra Three.js
