# Projet en autonomie

Un petit jeu ou une animation, à vous

---

## Le cadre

- **Seul**, sujet libre
- Ce soir : choisir et commencer
- Demain, de 13h30 à 16h15 : avancer, avec de l'aide
- Demain, 16h15 : **5 minutes** de présentation chacun
- Un bon sujet est un sujet que vous pouvez **finir**

---

## Choisir son sujet

| Sujet | Outils |
| --- | --- |
| Carte ou page animée | CSS, GSAP |
| Attrape-objets | JavaScript, GSAP |
| Memory | JavaScript, GSAP |
| Jeu 2D | Phaser (demain matin) |
| Scène 3D animée | Three.js (demain matin) |

<!--
Ce soir, CSS, JavaScript et GSAP suffisent pour les trois premiers sujets.
-->

---

## Critères minimum

- Au moins **3 animations**, dont une déclenchée par l'utilisateur
- **Aucune erreur** dans la console
- Un code **lisible** : fichiers séparés, noms clairs, commentaires

---

## La présentation

1. **Démonstration** : le projet tourne
2. **Le code** : montrez-nous où vous animez
3. **Une difficulté**, et comment vous l'avez résolue

---

## Par où commencer ?

1. Trois lignes sur papier : ce que fait le projet
2. La version la plus simple qui marche, **sans animation**
3. Les animations une par une, console ouverte
4. Les bonus, s'il reste du temps
