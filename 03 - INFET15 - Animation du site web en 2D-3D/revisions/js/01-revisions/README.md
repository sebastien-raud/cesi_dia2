# Révisions des bases de JavaScript

## Objectifs

Il y a plein d'exercices dans les répertoires `exos` sur les bases de JavaScript :

- types de données
- manipulation des variables
- conditions
- boucles
- algorithmes

Les exercices sont de plus en plus complexes.

Les énoncés sont dans les fichiers `script.js` de chaque répertoire.

Tout se passe dans la console du navigateur, il faut donc lancer le fichier `index.html` de  l'exercice
pour voir le résultat dans la console.

À toi de voir les exercices qui peuvent t'intéresser !

Au besoin, les corrections sont dans le répertoire `corrections`.

Et, s'il y a des questions (énoncé pas clair, correction pas simple, besoin de pistes pour avancer un exercice 
sans regarder la correction, ...), je suis là !
