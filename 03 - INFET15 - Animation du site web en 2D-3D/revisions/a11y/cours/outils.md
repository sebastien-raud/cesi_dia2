## Glossaire 

| Sigle  | Signification                                         | Notes                                    |
| ------ | ----------------------------------------------------- | ---------------------------------------- |
| `A11Y` | Accessibility                                         | 11 lettres entre le A et le Y            |
| `W3C`  | World World Web Consortium                            | organisme de standardisation pour le web |
| `WAI`  | Web Accessibility Initiative (1997)                   | initiative du W3C pour l'a11y            |
| `WCAG` | Web Content Accessibility Guidelines                  | ensemble de recommandations par la WAI  |
| `RWD`  | Responsive Web design                                 |                                          |
| `RGAA` | Référentiel Général d'amélioration de l'accessibilité | référentiel français                     |
| `ARIA` | Accessible Rich Internet Applications                 |                                          |


## Extensions Chrome 

- [Colorblindly](https://chromewebstore.google.com/detail/colorblindly/floniaahmccleoclneebhhmnjgdfijgg) : simulation déficiences visuelles 
- [HTML Code Sniffer](https://squizlabs.github.io/HTML_CodeSniffer/) : validateur de code HTML et normes WCAG
- [Web developer](https://chromewebstore.google.com/detail/web-developer/bfbameneiokkgbdmiekhjnmfkcnldhhm?hl=fr) : outils de développement comportant des aides pour l'accessibilité
- [Heading Maps](https://chromewebstore.google.com/detail/headingsmap/flbjommegcjonpdmenkdiocclhjacmbi) : hiérarchisation des titres

## Outils de vérification

- DevTools Chrome : 
  - Onglet `Lighthouse`
  - Onglet `HTML` > `Accessibility`
- [Validateur HTML du W3C](https://validator.w3.org/)
- [Vérifier le support des balises HTML](https://caniuse.com/)
- [Vérifier l'imbrication des balises HTML](https://caninclude.glitch.me/)
