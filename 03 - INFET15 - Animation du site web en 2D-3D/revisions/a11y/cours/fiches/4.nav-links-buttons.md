# Navigation, liens et boutons

## Liens et boutons

Un site web est constitué de plusieurs pages

Les liens sont essentiels pour naviguer entre elles, ou se déplacer à l'intérieur d'une page.

### Liens et boutons, comment les différencier ?

Liens, boutons = Composants d'interface

Ils peuvent visuellement se ressembler, mais ils ne sont pas perçus de la même façon par les lecteurs d’écrans

**Visuellement**, ils peuvent se ressembler, du moment que l’on comprend la finalité

Pour les lecteurs d’écrans 

- Listes séparées de liens ou de boutons
- Lisent “lien [intitulé]”  ou “bouton [intitulé]”

Navigation clavier

- Les liens sont activables avec la touche “entrée”
- Les boutons sont activables avec la touche “entrée” et la barre espace

#### Les liens = Naviguer

- Vers une autre page
- Vers une autre fenêtre
- Vers un document
- Vers un système de mail ou de téléphone

#### Les boutons = Action

- Ouvrir/fermer
- Lancer une action gérée par un script

### Les liens, la balise `<a href=”#”>`

`<a href="">` = La balise dédiée à la navigation

**Vers une autre page web** 

```html
<!-- Lien a avec attribut href  -->
<a href="index.html">Accueil</a>
```

**à l'intérieur d'une page : ancre interne**

```html
<!-- La valeur de l’attribut href commence par # de la valeur d'un attribut id placé sur l’élément vers lequel on se dirige -->
<a href="#id-1">Actualités</a>
[....]
<div id="id-1">[....]</div>
```

**Vers une nouvelle fenêtre ou un nouvel onglet**

```html
<!-- Attribut target=”_blank” -->
<a href="http://www.google.com" target="_blank">Actualités</a>
```

**Vers un document** 

```html
<!-- Attribut download -->
<a href="nom-fichier.pdf" download>Télécharger le compte rendu (PDF - 45Ko)</a>
<a href="nom-fichier.xls" download>Tableau de gestion (XLS 50ko)</a>
```

**Vers un numéro de téléphone**

```html
<!-- Lien téléphone-->
<a href="tel:+49.157.0156">+49 157 0156</a>
<a href="tel:+1(555)5309">(555) 5309</a>
```

**Vers une adresse mail**

```html
<!-- Lien mail -->
<a href="mailto:email@example.com">Envoyer Email</a>
<a href="mailto:email@example.com, secondemail@example.com">Envoyer Email à deux destinataires</a>
<a href="mailto:email@example.com?cc=secondemail@example.com">Envoyer Email avec copie à un autre</a>
<a href="mailto:email@example.com?subject=Mail de notre site Web ">Envoyer Email avec un sujet prédéfini</a>
<a href="mailto:email@example.com?body=Texte du message prédéfini">Envoyer Email avec un corps de message prédéfini</a>
```

### Un lien ne doit jamais être vide

Il existe plusieurs façons pour un lien d’être affiché 

- Lien textuel
- Lien image
- Lien composite : image + texte

La balise ```<a>``` doit toujours avoir un contenu

### Lien textuel uniquement

```html
<a href="#">
	Page suivante
</a>
```

#### À éviter : les tout petits mots

Posent des problèmes 

- Souris : Zone de clic réduite
- Lecteur d’écran : souvent un mot non compréhensible hors contexte

```html
Pour consulter votre commande cliquez <a href="#">ici</a>
```

Préférer un texte complet 

- Plus clair pour les lecteurs d'écran
- Agrandir la zone de clic

```html
<a href="#">Pour consulter votre commande cliquez ici</a>
```

#### Toujours privilégier la simplicité et le texte à l'intérieur de la balise

```html
Consulter les <a href="#">Conditions générales de vente</a>
```

#### Liens dans des blocs de texte

Quand ils sont intégrés dans un texte, les liens doivent pouvoir être distingués autrement que par la couleur

Souligner les liens qui se trouvent au milieu de texte

```html
Si vous désirez plus d'informations, vous pouvez consulter <a href="#">Le site officiel de recherche d'emploi</a>
```

### Lien images uniquement

C'est l'alternative textuelle de l'image qui sera prise en compte

- L’alternative textuelle est perçue par les lecteurs d’écrans
- Elle doit être explicite : **permettre de comprendre la direction du lien**


### Lien avec un contenu mixte : image + texte

C'est la combinaison de l'alternative textuelle de l'image et du texte qui sera prise en compte

Exemple avec une image `<img>` qui a du sens

```html
<a href="#">
	<img src="" alt="Voir">
	le détail de l'article
</a>
```

### Ajouter des informations complémentaires

#### Pour quels liens ?

Besoin de compléments d’information pour les liens qui ne sont pas explicites ("Lire la suite", etc.)

#### Aria-label

Le contenu doit au minimum reprendre le texte du lien

```html
Montres numériques
<a href="#" aria-label="En savoir plus sur nos montres numériques">En savoir plus</a>
Montres à gousset
<a href="#" aria-label="En savoir plus sur nos montres gousset">En savoir plus</a>
```

#### Title : ne doit être utilisé que pour apporter des informations complémentaires

Le contenu doit au minimum reprendre le texte du lien

```html
Montres numériques
<a href="#" title="En savoir plus sur nos montres numériques">En savoir plus</a>
Montres à gousset
<a href="#" title="En savoir plus sur nos montres gousset">En savoir plus</a>
```

### Aria-label ou title ?

Aria-label 

- Lu en priorité par les lecteurs d’écrans
- Non visible

Title

- Pas toujours lu par les lecteurs d’écran
- Visible uniquement au survol de la souris

### Bonnes pratiques pour les liens qui s'ouvrent dans une nouvelle fenêtre

C'est un lien `<a>` avec un attribut `target=_blank`

- Visuellement, ajouter un picto ↗️
    - En dur dans le code
    - En feuille de style
- Dans le code, ajouter une information “nouvelle fenêtre” à la fin du nom accessible

```html
<a href="#" target="_blank">
	Voir l'information sur le site dédié 
	<span class="sr-only">(nouvelle fenêtre)</span>
	<span class="ri-external-link-line" aria-hidden="true"></span>
</a>
```

### Bonnes pratiques pour les liens de téléchargement des documents

Quand on met un lien vers un document en téléchargement, 

- Nom du fichier + format + poids + langue si besoin

```html
<a href="#" target="_blank">
	Voir l'information sur le site dédié 
	<span class="sr-only">(nouvelle fenêtre)</span>
	<span class="ri-external-link-line" aria-hidden="true"></span>
</a>
```

À VÉRIFIER

Document en téléchargement dont les types de format sont reconnus compatibles avec l’accessibilité
- Microsoft Office (Word 2003, OOXML) ;
- Open Office Org (ODF) ;
- Adobe PDF ;
- Epub/Daisy.

Fournir une version accessible : 
- Le document en lui-même
- Une version html

## Navigation

### Les systèmes de navigation

Vérifier qu'il existe au moins 2 systèmes de navigation (pour tous), parmi : 
- Menu principal
- Moteur de recherche
- Plan du site

Vérifier que la position de ces systèmes de navigation :
- Visuellement (pour ceux qui voient)
- Dans le code (pour les lecteurs d’écrans)

### Qu’est-ce qu’un plan du site ?

Une liste de liens représentative de l’arborescence des pages du site web

C’est souvent une liste de liens, avec une imbrication éventuelle

### Le menu principal

- Titre “menu principal” ou “menu”
- Liste non ordonnée de liens

Donner la position courante dans un menu

- Visuellement : bordure, mise en gras, Picto…
- Dans le code avec un attribut `aria-current=”true”` (pour les lecteurs d’écrans)

```html
	<nav role="navigation" aria-label="Menu principal">
		<ul >
			<li><a href="#" aria-current="true">Accueil</a></li>
			<li><a href="#">Rubrique 1</a></li>
			<li><a href="#">Rubrique 2</a></li>
		</ul>
	</nav>
</div>
```

### Le Fil d’Ariane

- Titre “Vous êtes ici”
- Liste ordonnée
- Séparateurs cachés aux lecteurs d’écran

```html
	<nav role="navigation" aria-label="Vous êtes ici">
		<ol>
			<li><a href="#">Accueil</a></li>
			<li><span aria-hidden="true">> </span><a href="#">Rubrique</a></li>
			<li><span aria-hidden="true">> </span><a>Page</a></li>
		</ol>
	</nav>
</div>
```

## Liens : `sr-only` ou `aria-label` ?

### Intitulé de lien

Regarder ce qu'il y a dans les balises `<a></a>`.

2 cas problématiques :
- Lien vide
- Lien non explicite

### Cas n°1 : lien vide

Exemple :

```html
<a href="#"><span></span></a>
```

=> Utiliser la classe `.sr-only`.

```html
<a href="#">
    <span aria-hidden="true"></span> <!-- Si le <span> contient une icône, le masquer avec aria-hidden="true" -->
    <span class="sr-only">Apprendre à utiliser ARIA</span>
</a>
```

Autres solutions :

```html
<a href="#"><img src="#" alt="Apprendre à utiliser ARIA"></a>
<a href="#"><svg role="img" aria-label="Apprendre à utiliser ARIA"></svg></a>
```

### Cas n°2 : lien non explicite

Exemple :
```html
<a href="#">Lire la suite</a>
```

=> Utiliser l'attribut `aria-label`.
```html
<a href="#" aria-label="Lire la suite : Apprendre à utiliser ARIA">Lire la suite</a>
```
