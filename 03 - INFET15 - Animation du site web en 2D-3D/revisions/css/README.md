# Défis CSS d'animation

Six petits défis pour s'entraîner aux animations CSS, du plus simple au plus avancé. Chaque défi est indépendant.

Le principe : une page `cible.html` montre le **résultat attendu**, en direct. La page `index.html` est la même, sans animation : à toi d'écrire le CSS dans `style.css` pour obtenir le même résultat. Chaque énoncé guide pas à pas, avec des aides à déplier, et la correction est dans `correction.css`.

| Défi | Résultat attendu |
| --- | --- |
| [01 : le bouton « J'aime »](01-bouton-j-aime/README.md) | Un cœur qui bat, un bouton qui se soulève au survol et s'enfonce au clic |
| [02 : le soulignement animé](02-soulignement-anime/README.md) | Des liens de menu dont le soulignement se dessine de gauche à droite au survol |
| [03 : le loader à trois points](03-loader-trois-points/README.md) | Trois points qui sautent l'un après l'autre, en vague |
| [04 : le menu burger](04-menu-burger/README.md) | Trois barres qui se transforment en croix, et un menu qui glisse depuis la gauche |
| [05 : la carte qui se retourne](05-carte-qui-se-retourne/README.md) | Des cartes devinettes qui pivotent en 3D pour montrer la réponse |
| [06 : la machine à écrire](06-machine-a-ecrire/README.md) | Un titre qui s'écrit lettre par lettre, avec un curseur qui clignote |

Pour réviser les notions : le [mémo « Animer une page web »](../memo-animer-une-page.md), parties 2 et 3.
